# Telegram бот для контроля замены предметов

Бот позволяет:
- добавить предмет и дату его замены;
- добавить срок использования предмета (например, 2 недели);
- показать список предметов;
- выбрать предмет и увидеть дату замены и оставшееся время использования;
- получать ежедневные напоминания о просроченных предметах в 19:00 по Москве.

Данные хранятся в MySQL и разделяются по `chat_id`, поэтому бот работает как в личных чатах, так и в группах.

## Функционал

- Кнопка `Добавить предмет и дату`:
  1. бот спрашивает название предмета;
  2. бот спрашивает дату в формате `ДД.ММ.ГГГГ`;
  3. бот спрашивает срок использования (`14 дней`, `2 недели`, `1 месяц`);
  4. запись сохраняется в MySQL.

- Кнопка `Обновить дату замены` (или команда `/update_date`):
  1. бот показывает список предметов в текущем чате;
  2. вы выбираете нужный предмет;
  3. вводите новую дату замены в формате `ДД.ММ.ГГГГ`;
  4. бот обновляет дату, не меняя срок использования.

- Кнопка `Удалить предмет` (или команда `/delete_item`):
  1. бот показывает список предметов в текущем чате;
  2. вы выбираете предмет;
  3. подтверждаете удаление;
  4. запись удаляется из MySQL.

- Кнопка `Показать предмет и дату`:
  1. бот показывает список уже добавленных предметов (inline-кнопки);
  2. после выбора предмета показывает:
     - дату замены;
     - срок использования;
     - дату окончания срока;
     - сколько времени осталось (или насколько просрочено).

Команда `/list` делает то же самое, что и кнопка `Показать предмет и дату` (удобно для групп).

Если предмет с тем же названием уже есть в этом чате, дата обновляется.

Напоминания о просрочке отправляются в каждый чат ежедневно в `19:00` по часовому поясу `Europe/Moscow`.

## Установка

1. Установите Python 3.10+ и MySQL.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте `.env` на основе примера:

```bash
copy .env.example .env
```

4. Заполните `.env`:
- `BOT_TOKEN` - токен бота из BotFather;
- `MYSQL_*` - параметры подключения к MySQL.

## Запуск

```bash
python bot.py
```

При старте бот автоматически:
- создаст БД (если не существует);
- создаст таблицу `replacements` (если не существует).

## Добавление в группу

1. Добавьте бота в нужную группу.
2. Выдайте права на отправку сообщений.
3. В BotFather отключите privacy mode (`/setprivacy -> Disable`), чтобы бот обрабатывал текстовые кнопки в группе.
4. В группе вызовите `/start`, после чего используйте кнопки.
